# Per-version evaluation (appendix to fusion-evaluation-2026-11.md)

For every true label in the labelled datasets (thesis `data/test/merged/labeled.jsonl`,
joined per connection by client and server address), what each method answers. Columns,
as a share of the connections the method answered:

- **single right**: one version, and it is the true one.
- **set has truth**: several alternatives (`{10|7|8.1}`, `a | b`), one of them true.
- **family only**: the right family, but no version (or none to compare with).
- **wrong version**: the right family, a version that is not the true one.
- **wrong family**: another OS family.

Most common answers are the method's label as it says it (tcpcluster and fusion as
`family / versions`). Generated by `per_version.py` (`D:\Documents\telltale-stats\eval-all`)
over the os_stats TSVs of 2026-11-25. In-sample for tcpcluster.
